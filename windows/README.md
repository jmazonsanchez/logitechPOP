# 🪟 LogiPop Sync para Windows

Soporte nativo para alternar y sincronizar periféricos **Logitech POP Keys** y **Logitech POP Mouse** desde sistemas **Windows 10 / 11**.

---

## 🚀 Instalación Rápida (1 Clic)

1. Descarga o clona esta carpeta en tu PC con Windows.
2. Entra en la carpeta `windows` y haz doble clic sobre:
   👉 **`setup.bat`**

### ¿Qué hace el instalador?
* Compila automáticamente la aplicación nativa ultraligera `LogiPop.exe` utilizando el compilador oficial de .NET incluido en Windows (`csc.exe`). **No requiere instalar Visual Studio, Python ni herramientas de terceros.**
* Coloca un acceso directo en tu carpeta de inicio para que arranque automáticamente en segundo plano junto con Windows.
* Se aloja de forma invisible en la bandeja del sistema (junto al reloj), consumiendo menos de 5 MB de RAM.

---

## ⌨️ Atajos Globales en Windows

Desde cualquier aplicación o juego en Windows, presiona:

* <kbd>Win</kbd> + <kbd>Alt</kbd> + <kbd>1</kbd> ➔ Cambiar teclado y ratón al **Dispositivo 1** (ej. tu laptop Linux)
* <kbd>Win</kbd> + <kbd>Alt</kbd> + <kbd>2</kbd> ➔ Cambiar teclado y ratón al **Dispositivo 2**
* <kbd>Win</kbd> + <kbd>Alt</kbd> + <kbd>3</kbd> ➔ Cambiar teclado y ratón al **Dispositivo 3**

---

## 🗑️ Desinstalación

Para eliminar la aplicación y volver al estado de fábrica, simplemente haz doble clic sobre:
👉 **`uninstall.bat`**
